Krátky opis hry

Hra je variácia klasického "Hada" (Snake). Hráč (alebo agent) ovláda hlavu hada na pravidelnej mriežke, zberom potravy sa had predlžuje. Cieľom agenta je získavať potravu a prežiť čo najdlhšie bez nárazu do stien alebo vlastného tela. Projekt obsahuje:

  • manuálnu verziu hry (pygame) pre ručné hranie,
  • prostredie optimalizované pre RL (SnakeGameAI) s odmeňovaním a frame-limitom,
  • DQN agenta (Linear_QNet + QTrainer) s Experience Replay a online + long memory tréningom.

Čo je už hotové

  • Funkčná manuálna verzia hry (`snake_game.py`).
  • RL prostredie pre agenta (`snake_game_ai.py`) so správou kolízií a odmien.
  • Implementácia DQN (model: `model.py`, tréner `QTrainer`).
  • Agent + tréningový skript (`agent.py`) so skúsenostnou pamäťou a ukladaním modelu.
  • Vizualizácia priebehu tréningu (`helper.py`) – live plot skóre a priemerov.
  • Pomocný skript pre kontrolu uloženého modelu (`inspect_model.py`).
  • Príklady výsledkov a záznamy: videá porovnania a timelapse + uložené váhy modelu.

Plán na druhý semester

  1. Rozšírenie experimen­tov: hyperparameter tuning (batch size, LR, gamma), dlhšie trénovanie.
  2. Lepšie logovanie a reproducibilita experimentov (config + seed + uložené kurzy).
  3. Rozšírenie stavového vektora a možná zmena architektúry (napr. viac skrytých vrstiev / conv prvky).
  4. Experimenty so stratégiou explorácie (epsilon schedule / Boltzmann) a reward shaping.
  5. Príprava datasetu/nástrojov pre self-play / multi-agent (možný presun k Hungry-Geese štýlu).
  6. Finalizácia dokumentácie, správa experimentov, a spracovanie výsledkov do záverečnej práce.
